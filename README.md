Top Down Space is a fast, top-down free-for-all. You pilot a lead ship around an enclosed arena, grow it into a fleet by collecting power-ups, and fight other fleets — human or AI — until only one commander is left flying.

Every match runs the same three phases:

Setup — choose how many human players (1–3), how many bot fleets (0–100), a bot difficulty tier, and any modules to enable.
Countdown & Battle — a 3-second countdown, then free-for-all combat until one fleet remains.
Victory — the last surviving commander is declared the winner. Press any key, or use the buttons, to rematch or return to the menu.
